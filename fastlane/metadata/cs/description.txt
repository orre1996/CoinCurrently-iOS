SOUKROMÉ OD ZÁKLADU

Vaše data zůstávají v zařízení. Neshromažďujeme osobní údaje, nic neprodáváme a vaši aktivitu nesdílíme s inzerenty. Žádné reklamní sítě, žádná reklamní ID a žádné trackery třetích stran, které sledují, na co se díváte.

• Bez registrace — otevřete aplikaci a začněte
• Bez účtu, bez e-mailu, bez telefonního čísla
• Nikdy žádné reklamy
• Bez reklamních ID a bez sledování napříč aplikacemi
• Neshromažďují se žádné osobní údaje
• Peněženky, transakce a nastavení zůstávají lokálně v zařízení
• Biometrický zámek (Face ID / Touch ID), aby aplikace zůstala soukromá

Jediná analytika, kterou používáme, je Aptabase — open-source nástroj, který dává soukromí na první místo. Zaznamenává anonymní, souhrnné události (třeba „aplikace otevřena“ nebo „graf zobrazen“), abychom mohli opravovat chyby a aplikaci zlepšovat. Žádná ID uživatelů, žádné IP adresy, žádné osobní údaje — nikdy.

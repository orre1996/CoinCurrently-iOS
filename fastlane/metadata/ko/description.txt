CoinCurrently는 암호화폐를 비공개로, 익명으로 추적하는 방법입니다. 가입 없음. 계정 없음. 광고 없음. 개인 데이터 없음. 모두를 위해 만든 빠르고 단정한 암호화폐 트래커입니다.

설계부터 프라이빗

데이터는 기기에 남습니다. 개인 정보를 모으지 않고, 아무것도 팔지 않으며, 활동을 광고주와 공유하지 않습니다. 광고 네트워크도, 광고 ID도, 무엇을 보는지 지켜보는 제3자 트래커도 없습니다.

• 가입 없이 — 앱을 열고 바로 시작
• 계정, 이메일, 전화번호 없음
• 광고는 없습니다
• 광고 ID 없음, 앱을 넘나드는 추적 없음
• 개인 데이터를 수집하지 않습니다
• 지갑, 거래, 설정은 기기에 로컬로 저장됩니다
• 앱을 비공개로 지키는 생체 잠금 (Face ID / Touch ID)

우리가 쓰는 분석은 Aptabase 하나뿐입니다. 프라이버시를 최우선으로 하는 오픈 소스 도구로, “앱을 열었다”나 “차트를 보았다” 같은 익명 집계 이벤트만 기록해 버그를 고치고 앱을 개선합니다. 사용자 ID 없음. IP 주소 없음. 개인 데이터 없음.

모두를 위한 접근성

암호화폐는 모두를 위한 것이어야 합니다. CoinCurrently는 앱 전체에서 접근성을 지원합니다.

• VoiceOver — 홈과 마켓부터 포트폴리오, 뉴스, 설정까지 모든 화면에 레이블이 있고 끝까지 이동할 수 있습니다
• Dynamic Type — 글자 크기가 시스템 설정을 따라 읽기 쉽습니다
• 색각 모드 — 설정에서 가격 변동을 녹색/빨간색에서 파란색/주황색으로 바꿉니다
• 라이트와 다크, 모두 대비가 높은 깨끗한 화면

실시간 시세와 차트

10,000개가 넘는 코인과 토큰의 실시간 데이터와 자세한 가격 기록. Bitcoin(BTC), Ethereum(ETH), 그리고 신경 쓰는 모든 알트코인을 정확한 시장 데이터, 거래량 기록, 여러 시간 단위 차트로 추적합니다.
